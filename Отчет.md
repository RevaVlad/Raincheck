# SLA

## Использованные метрики

| Метрика | Что измеряет |
| --- | --- |
| `raincheck_probe_checks_total` | Количество проверок по операции и результату. |
| `raincheck_probe_duration_seconds` | Длительность проверок в секундах. |
| `http_request_duration_seconds` | Длительность HTTP-запросов. Счётчик `_count` используется для подсчёта всех попыток, включая ошибки. |
| `raincheck_groups_created_total` | Количество созданных групп. |
| `raincheck_polls_created_total` | Количество созданных опросов. |
| `raincheck_responses_created_total` | Количество созданных черновиков ответов. |

## SLI и SLO

Выбрал SLI как долю проверок с корректным результатом в пределах заданного времени.

| Операция | Ограничение времени |
| --- | --- |
| Чтение опроса | 500 мс |
| Сохранение ответа с проверкой чтением | 1 с |
| Получение результатов | 1 с |

```text
SLI(T) = успешные проверки за T / все проверки за T × 100%
SLI создания(T) = созданные сущности за T / POST-запросы к соответствующему маршруту за T × 100%
SLO: каждый SLI за 5 минут ≥ 99%
```

SLI создания рассчитывается отдельно для групп, опросов и ответов. В знаменатель входят все HTTP-статусы, включая ошибки валидации и конфликты. При отсутствии измерений значение SLI отсутствует.

## SLA

Для учебного приложения задал SLA: не менее 99% успешных проверок каждой из трёх операций за 30 дней.

```text
SLA-показатель = min(SLI чтения(30 дней), SLI сохранения(30 дней), SLI результатов(30 дней))
Условие SLA: SLA-показатель ≥ 99%
```

На дашборде показан демонстрационный минимум за 5 минут. Он не подтверждает выполнение SLA за 30 дней.

## Изменения приложения и скринкаст

- Добавил отдельный пробер: проверяет чтение опроса, сохранение ответа и получение результатов. Метрики собираются через vmagent в VictoriaMetrics.
- Настроил HTTP-метрики backend для расчёта SLI создания сущностей.
- Добавил дашборд VMUI с SLI операций, демонстрационным SLA-показателем и успешностью создания сущностей.

Для скринкаста подготовил временной промежуток в котором запросы падали, после сделал несколько успешных запросов через ui чтобы поправить метрики.

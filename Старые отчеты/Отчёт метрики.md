# Метрики Raincheck

## Использованные экспортеры

Для метрик Node.js использовал библиотеку `@prometheus-io/client`.

Для PostgreSQL использовал готовый образ `prometheuscommunity/postgres-exporter:v0.18.1`. Exporter запущен отдельным Deployment в namespace `monitoring`. Он подключается к `postgres.raincheck.svc.cluster.local:5432/raincheck` и отдаёт метрики на порту `9187`, путь `/metrics`. Пароль получает из Secret `postgres-exporter-env`.

## Бизнес-метрики

Реализовал четыре метрики типа Counter. Они увеличиваются после успешной записи соответствующего объекта в БД.

| Метрика | Что считает |
| --- | --- |
| `raincheck_groups_created_total` | Количество успешно созданных групп. |
| `raincheck_participants_created_total` | Количество участников, успешно присоединившихся к группам. |
| `raincheck_polls_created_total` | Количество успешно созданных опросов. |
| `raincheck_responses_created_total` | Количество созданных черновиков ответов на опросы. Подтверждение и изменение ответа отдельно не увеличивают этот счётчик. |
| `raincheck_poll_lifetime` | Время от создания опроса до его завершения. |

## Сбор метрик в VictoriaMetrics

VictoriaMetrics, vmagent и PostgreSQL exporter находятся в namespace `monitoring`, приложение и PostgreSQL — в `raincheck`. Vmagent запрашивает метрики каждые 15 секунд и отправляет их в VictoriaMetrics через remote write.

Использованные манифесты:

- [30-api.yaml](../k8s/30-api.yaml) — Deployment API с аннотациями и внутренним портом метрик.
- [70-victoria-metrics-values.yaml](../k8s/70-victoria-metrics-values.yaml) — общие настройки VictoriaMetrics и vmagent.
- [80-postgres-exporter.yaml](../k8s/80-postgres-exporter.yaml) — PostgreSQL exporter.
